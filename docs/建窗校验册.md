# 建窗校验册（window_create registry）

> 本册钉死**业务窗创建写路径**的唯一正确性口径。选定后**当天禁止改口**。
> 偏离本册的建窗写路径一律**拒写**，并在 `audit_trail` 记动作 `建窗偏了`。

## 一、选定口径：甲路径（整笔拒绝）

- **甲路径（本仓唯一在用）**：创建前整笔校验，时间倒挂或重名时**整笔拒绝**，
  `windows` 表**零增**，并写审计 `window_create_reject`。
- 乙路径（先落 `window_draft` 再原子转正式、失败草稿回滚）**已废弃，不得落地**。
- 甲、乙两边**不得混用**：本仓不创建 `window_draft` 表，任何代码不得引入草稿表/草稿写入。

落账日期：以 `window_create_registry.chosen_date = date('now')` 当日为准，
当日该行的 `chosen_path` 只允许是 `'甲'`，由 SQLite 触发器 `trg_registry_no_flip_today`
阻止当日把 `chosen_path` 改成别的值（当日改口即抛错）。

## 二、建窗写路径强制规则（甲路径）

1. 先读校验册：`active=1` 且 `chosen_path='甲'`，否则拒写并记 `建窗偏了`。
2. 占建窗锁，锁键 `window_create:{name}`：
   - 后到者拿不到锁 → 只记争用（`contention_log` + 审计 `window_create_contention`），
     返回 409，**不写任何业务行**。
3. 创建前整笔校验（任一不过即整笔拒绝，`windows` 零增，写 `window_create_reject`）：
   - 时间合法：严格 `open_at < close_at`（相等或倒挂均拒）。
   - 名称唯一：`name` 不得与既有窗重名（重名不得覆盖旧世代）。
4. 校验通过才在**同一事务**内 `INSERT windows` + 写审计 `window_create` + 提交。
5. 任一步抛错 → 回滚，正式表零增。

## 三、状态码约定

| 情形 | 状态码 | 审计动作 |
|------|--------|----------|
| 时间倒挂 / 相等 / 重名 | 400 | `window_create_reject` |
| 建窗锁争用（后到） | 409 | `window_create_contention`（+ contention_log） |
| 校验册偏离（active=0 / 口径非甲） | 409 | `建窗偏了` |
| 合法创建成功 | 200 | `window_create` |

## 四、五处同态

窗口列表（`GET /api/windows`）、详情卡（`GET /api/windows/{id}`）、
审计流水（`audit_trail`）、种子夹具装载（`db.seed_if_empty` 复用同一校验函数）、
争用（`contention_log`）五处对同一事实（窗是否合法落库、为何被拒、谁后到）口径一致：
非法窗在任何一处都不得呈现为已存在的正式窗。

## 五、边界约束（来自任务）

- 网页不另起：沿用现有 FastAPI + Vue 单页，不新增服务/页面。
- 登录保留：`auth.py` 会话机制不变。
- 库文件继续挂：`data/app.db` 与 docker 卷挂载不变，仅新增表，不改既有表结构语义。
- 本地夹具、SQLite；只改前端提示不算数，校验必须在服务端写路径钉死。
